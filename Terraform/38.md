# 38 

he Nautilus DevOps team is automating IAM user creation using Terraform for better identity management.

For this task, create an AWS IAM User using Terraform with the following requirements:

The IAM User name iamuser_ammar should be stored in a variable named KKE_user.
Note:

1. The configuration values should be stored in a variables.tf file.

2. The Terraform script should be structured with a main.tf file referencing variables.tf.
The Terraform working directory is /home/bob/terraform.

Right-click under the EXPLORER section in VS Code and select Open in Integrated Terminal to launch the terminal.

---

Follow these steps to create an AWS IAM User using Terraform.

### **Step 1: Navigate to Terraform directory**

```
cd /home/bob/terraform
```

### **Step 2: Update&#x20;**`variables.tf`

Add the following variable:

```
variable "KKE_user" {
  description = "IAM user name"
  type        = string
  default     = "iamuser_ammar"
}
```

### **Step 3: Update&#x20;**`main.tf`

Add the following Terraform resource:

```
resource "aws_iam_user" "iam_user" {
  name = var.KKE_user
}
```

**Explanation:**

- `aws_iam_user`: Terraform resource for creating an AWS IAM user.
- `name`: References the variable defined in `variables.tf`.
- `var.KKE_user`: Supplies the IAM username `iamuser_ammar`.

### **Step 4: Initialize Terraform**

```
terraform init
```

### **Step 5: Validate configuration**

```
terraform validate
```

### **Step 6: Preview and create IAM User**

```
terraform plan
terraform apply
```

Enter `yes` when prompted.

### **Step 7: Verify IAM User**

```
aws iam get-user --user-name iamuser_ammar
```

### **Expected configuration**

| Requirement        | Value                   |
| ------------------ | ----------------------- |
| Terraform resource | `aws_iam_user.iam_user` |
| Variable name      | `KKE_user`              |
| IAM username       | `iamuser_ammar`         |
| Variables file     | `variables.tf`          |
| Main file          | `main.tf`               |
| Working directory  | `/home/bob/terraform`   |

**Important:** Keep both `main.tf` and `variables.tf`. Terraform automatically loads both files from the working directory.
